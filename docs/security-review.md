# 发布安全说明

检查日期：2026-10-25。

## 发布范围

仓库来自一个本地 HTML 阅读器，仅包含应用代码、必要的浏览器库、示例、测试和说明文档。未复制来源文件所在目录的其他项目、个人文档、阅读记录或开发环境。检查过程中未读取任何 `.env` 或 `.env.*` 文件。

## 密钥检查

原始 HTML 和最终提交文件分别检查。最终扫描以 Git 暂存区的实际内容为对象，使用 Gitleaks 8.30.1 默认规则，并补充常见服务密钥前缀、私钥头、JWT 与凭据赋值规则；不使用被检仓库自带的规则豁免。扫描未发现真实 API Key 或其他已确认凭据。

发布版从全新的提交历史开始，不带来源目录的其他历史。`.gitignore` 排除了环境配置、私钥、个人文档目录、进度导出与开发依赖。扫描只能覆盖本次发布的文件与规则可识别的内容，不代表未来提交也已接受检查。

## 本次修复

原页面将 Markdown 解析结果直接写入 HTML，导入不可信文档时存在脚本注入风险。发布版先通过 Marked 解析，再使用 DOMPurify 的 HTML 配置清洗，之后才插入阅读区域；TXT 通过 `textContent` 显示。

浏览器库固定版本并保存在 `assets/vendor/`，页面不再依赖未固定版本的运行时 CDN。仓库保留对应许可证与版本哈希；更新方式见 `scripts/vendor.mjs` 和第三方说明。

进度读取会校验文件名和位置，损坏 JSON、存储访问受限均不会阻止普通阅读。记录导出后会释放临时 Blob URL；异步文件读取使用序号避免旧结果覆盖新文档。

## 数据流与边界

页面没有后端、账号或 API Key，也没有上传正文的接口。正文只留在页面内存，localStorage 保存文件名、滚动位置和时间；导出的 JSON 也不包含正文。

Markdown 中的远程图片和链接仍可能产生网络请求。HTML 清洗旨在降低脚本注入风险，不会把所有外部资源转换成本地资源。浏览器插件、浏览器本身和操作系统的行为不属于本应用的控制范围。
